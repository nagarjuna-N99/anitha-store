# Anitha Pemmasani store: public website

`index.html` is the **customers' website only**. It has no admin screens and no PIN.
The owner manages the shop in a separate app on the server (`https://YOUR-SERVER/admin`), behind a password.

- Without a server address built in, this page is a **demo** that saves only in the visitor's own browser.
- With the server address built in (see HOW-IT-WORKS/17), it shows exactly what the owner published.
