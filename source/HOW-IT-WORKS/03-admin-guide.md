# 03 · Admin guide

Open the store → **Switch to Admin** → PIN.

| Tab | Use it to |
|---|---|
| Dashboard | interactive overview: pick a period, see revenue / orders / customers with change versus before, a chart you can tap, what needs your attention (each item opens its tab), best sellers, sales by category and source, stock snapshot, activity |
| Home Page | show/hide Recently sold, change hero images/text/schedule, choose home categories, announcement bar |
| Products | **saved drafts grouped by category (below the list)**, **bulk upload from a CSV sheet**, **📲 Status** picture maker, add/edit sarees (multi-photo, video URL, fabric, colours, AI-style tags & description, SEO fields), stock, "🔔 n waiting" badge |
| Categories | manage saree categories and, in a separate section, accessory categories |
| Image Studio / Saved Drafts | prepare product photos, many photos per product. **Save product draft** asks for the product details (with ✨ AI fill); a complete draft is *Ready to post* and goes live with one tap (**🚀 Post now**, or **Post all ready**); drafts are grouped by category with Ready / Needs-details filters |
| Orders | website and imported WhatsApp orders; statuses (placed → confirmed → packed → shipped (asks courier + link) → out for delivery → delivered); **Slip** prints the packing slip; badges for gifts and address changes; invoices |
| Reviews | approve / reject / reply / delete; auto-publish switch |
| Delivery & Gifting | delivery zones and days, PIN codes that need a check (customers can still order), gift wrapping fee, a "try a PIN" box, and the no-cancel policy note |
| WhatsApp Assistant | **ON/OFF switch for taking orders in the chat**, chat button + number, policies the assistant may state, connect/publish to the assistant server, cart-reminder results, paid WhatsApp orders import, setup checklist |
| Stock Alerts | who waits for which saree; message queue |
| Invoices, Customers, Statements | billing and customer lists |
| Instagram | scheduled and posted Instagram items, connection status, plan a post (owner app only); every product also has a 📸 button and the *Share on Instagram* window after publishing |
| AI Helper | ten AI drafting tools plus switches (see `15-ai-helper.md`) |
| Bundles | "buy together & save" offers: pick items, set percent or flat discount; pause or delete (website orders only) |
| Coupons | create codes with rules (min order, expiry, max uses, first-order only, once per customer, website/WhatsApp, "assistant may mention") |
| Audit Logs, Settings | history; business details, SEO pack, login service address, review settings |

**Common jobs**
- *Saree from Image Studio:* edit the photos → **Save product draft** → fill the dialog (press ✨ for AI to write the description, tags, fabric and colours; add the price) → **🚀 Save & post now**, or save it and post later from Saved Drafts.
- *New saree:* Products → Add → photos → Fabric/Colours → Generate description → Save. Then (once hosted) **Send sarees & policies** in WhatsApp Assistant so the assistant knows it (or tick "send automatically").
- *Many sarees at once:* Products → ⬇ CSV template → fill → ⬆ Bulk upload → check the preview → Add.
- *Post a saree on WhatsApp status:* Products → 📲 Status → Download.
- *Restock:* edit stock → customers waiting for alerts are queued one message each.
- *Price change:* edit the product; republish to the assistant.
- *Approve review:* Reviews → Pending → Publish.
- *Paid WhatsApp order arrives:* assistant inbox (`/inbox` on the assistant server) → Send payment link → customer pays → Mark shipped → store admin → WhatsApp Assistant → **Add paid orders to the store**.
